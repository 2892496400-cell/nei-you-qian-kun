PASSWORD SETTINGS

全网更新密码

此网站从 GitHub 的 password-config.json 读取密码。修改该文件并提交后，所有访客刷新页面都会读取新的密码。

  1. 打开仓库中的 password-config.json。
  2. 点击编辑图标，将 password 后的值改为新密码。
  3. 点击 “Commit changes”。

GitHub Pages 通常约 1 分钟完成部署，随后全网同步。
